# Конвенція папок і файлів тижневого випуску

```
2026-W40_nazva-gazety/
  01/
    1_1_lider-tyzhnya.docx
    1_1_lider-tyzhnya.jpg
    1_2_korotko.docx
  02/
    2_1_sport.docx
    2_1_sport.jpg
  ...
```

## Правила

- Кожна **сторінкова підпапка** називається номером сторінки (наприклад, `01`, `02`) — саме ця назва є авторитетним джерелом "якій сторінці належить контент".
- Кожен **файл контенту** називається за схемою `{page}_{order}_{slug}`:
  - `page` — номер сторінки (дублює назву папки; якщо не збігається — Рівень 1 видасть попередження, але не помилку);
  - `order` — порядковий номер статті на цій сторінці (використовується для сортування, коли на сторінці кілька статей);
  - `slug` — довільна коротка назва статті.
- Текст і фото однієї статті мають **однаковий stem** (усе, крім розширення): `1_1_lider-tyzhnya.docx` ↔ `1_1_lider-tyzhnya.jpg`.
- Дозволені розширення тексту: `.docx`, `.doc`, `.txt`. Дозволені розширення фото: `.jpg`, `.jpeg`, `.png`, `.tif`, `.tiff`.
- Стаття без фото — нормально. Фото без тексту — помилка конвенції (звіт Рівня 1 це підсвітить).
- Кількість статей на сторінку **не фіксована** — визначається тим, скільки файлів фактично поклали в папку сторінки цього тижня.
- Стаття **ніколи не ділиться між сторінками**: вона або повністю влазить на свою призначену сторінку цього номера, або переноситься цілим блоком у наступний тижневий випуск (окрема папка наступного тижня).

## Структура тексту всередині файлу статті (заголовок/лід/тіло)

Щоб Рівень 2 міг вставляти реальний текст у відповідні фрейми InDesign (а не
лише переприв'язувати фото), кожен текстовий файл статті повинен розрізняти
три частини: **заголовок**, (необов'язковий) **лід** і **тіло**.

**Для `.docx`** — розрізнення за стилем абзацу Word (назва стилю
розпізнається за підрядком, без урахування регістру, тож не обов'язково
збігатися точно):

| Частина | Підказки в назві стилю Word |
|---|---|
| Заголовок | "заголовок", "title", "heading" |
| Лід | "лід", "лид", "vrizka", "lead" |
| Тіло | будь-який інший стиль (або "Обычный"/"Normal") |

Перший непорожній абзац зі стилем-підказкою заголовка — заголовок статті.
Перший непорожній абзац зі стилем-підказкою ліда — лід (може бути відсутній).
Усі інші непорожні абзаци, у порядку появи, — тіло.

Якщо жоден абзац не має розпізнаного стилю (наприклад, увесь текст набрано
стилем за замовчуванням) — Рівень 1 застосовує позиційний резервний варіант,
той самий, що й для `.txt` нижче, і додає попередження "стилі не розпізнано,
використано позиційний резерв", щоб верстальниця могла перевірити результат.

**Для `.txt`** (стилів немає в принципі) — позиційний варіант за кількістю
непорожніх рядків:
- 1 рядок — це заголовок, лід і тіло порожні.
- 2 рядки — перший рядок заголовок, другий — тіло (ліда немає).
- 3+ рядків — перший рядок заголовок; другий рядок — лід, лише якщо він
  коротший за 240 символів (інакше одразу йде в тіло); решта — тіло.

Ці правила — початкова, найпростіша робоча версія; якщо на практиці
виявиться, що верстальниця регулярно пише інакше, конвенцію можна буде
уточнити пізніше без зміни формату папок/файлів.
