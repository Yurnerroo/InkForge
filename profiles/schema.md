# Формат профілю газети

Кожна газета, з якою працює Рівень 2, описується одним YAML-файлом у цій папці
(`profiles/<id>.yaml`). Рушій Рівня 2 не повинен містити жодної назви стилю,
фрейма чи кольорового патерну — усе специфічне для шаблону читається звідси.

Профіль будується за принципом "базові значення за замовчуванням +
перевизначення на газету": якщо в майбутньому з'явиться спільна база стилів
(див. `docs/architecture.md`, розділ "Крос-газетна перевірка"), вона піде в
окремий `_base.yaml`, а профілі газет успадковуватимуть з нього лише те, що
збігається. Поки що бази немає — усі поля профілю самодостатні.

## Поля

| Поле | Тип | Опис |
|---|---|---|
| `id` | string | Короткий slug газети, збігається з іменем файлу (`ty_i_ya`, `mif`, `dyhovnist`, ...). |
| `display_name` | string | Людська назва газети. |
| `page_count` | int | Загальна кількість сторінок у стандартному випуску. |
| `manual_pages` | list[int] | Сторінки, які верстальниця завжди робить вручну — Рівень 2 їх не чіпає. |
| `manual_pages_uncertain` | list[int] | Сторінки, статус яких (ручна/автоматична) ще не підтверджено — потребують уточнення. |
| `spreads` | list[object] | Розвороти в порядку номера сторінки: `{pages: [n, n+1], color_mode: grayscale\|cmyk\|mixed}`. |
| `color_alternation_pattern` | string | Короткий людський опис патерну (напр. "через розворот", "фіксовані позиції", "відсутній — усе ч/б"). |
| `cmyk_profile` | string \| null | Назва ICC/газетного CMYK-профілю друку, якщо підтверджено; інакше `null`. |
| `photo_links.storage` | string | Завжди `linked` за поточними знахідками (не `embedded`). |
| `photo_links.naming_pattern` | string | Патерн імені файлу посилання у старому пакеті (лише для довідки — Рівень 2 підставляє свій файл, не парсить старе ім'я). |
| `paragraph_styles_found` | list[string] | Усі назви стилів абзаців, знайдені в зразках (сирий список). |
| `paragraph_style_roles` | object \| "TBD" | Мапа роль → назва(и) стилю, якщо підтверджено верстальницею; інакше рядок `"TBD"`. |
| `character_size_roles` | object \| "TBD" \| null | Опційне. Заповнюється лише коли `paragraph_style_roles` не працює (немає надійних іменованих стилів абзаців — див. `dyhovnist.yaml`) і роль визначається прямим розміром символу (`PointSize`) замість назви стилю. `null`, якщо метод не потрібен (є надійна мапа за стилем). |
| `headline_font_alternation` | object \| null | Опційне. Підтверджене верстальницею правило чергування шрифту заголовка між сусідніми статтями на одній сторінці (напр. `{method: alternate_by_article_order_on_page, fonts: [...], confirmed: true, note: ...}`). `null`, якщо газета не має такого правила або воно ще не підтверджено. |
| `special_pages` | list[object] | Сторінки з нестандартною структурою (напр. ТВ-програма): `{pages: [...], description: ..., automation: none}`. |
| `fonts_installed` | list[string] | Шрифти зі статусом `Installed` у зразках. |
| `fonts_substituted` | list[string] | Шрифти зі статусом `Substituted` у зразках — ризик підміни, перевірити перед запуском. |
| `frame_stability` | string | Завжди `partial` за поточними знахідками — стабільне ядро `Self` ID + динамічна звірка кількості. |
| `samples_analyzed` | list[string] | Які випуски проаналізовано (для трасування знахідок). |
| `notes` | string | Довільні нюанси, специфічні для газети. |

## Джерело даних

Профілі заповнені на основі ручного аналізу реальних `.idml`-зразків
(`samples/<id>/issueNN/`). Якщо якесь поле не вдалося підтвердити зі зразків —
воно позначається `null`/`"TBD"`, а не вгадується.
